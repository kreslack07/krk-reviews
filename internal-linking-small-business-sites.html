Internal Linking for Small-Business Sites: The Links Google Follows

Published 2026-11-21 · By KRK Digital Products (ABN 71 770 320 895, Australia)

A crawler finds pages by following links. A page with no link pointing at it can sit on a server indefinitely without appearing in search results, and the retrieval crawlers behind AI answers work the same way. On a small site, internal linking is the cheapest structural repair available.

This is the link-graph check inside our 48-hour AI & SEO website audit, written so you can run it yourself.

What counts as a link

Google's guidance on crawlable links is blunt: a link is crawlable when it is an <a> element with an href attribute, and most links in other formats are not parsed by the crawler.

  • Recommended: an anchor element carrying an href attribute, such as <a href="/services">.
  • Not recommended: a <span> carrying an href, or an anchor without an href that depends on a script to navigate.
  • Not recommended: navigation driven by a script event, such as an onclick handler that calls a function.

If a menu item or a "read more" control is a click handler rather than an anchor, the crawler may never see the destination.

Anchor text is the label a crawler reads

Anchor text is the visible text between the tags, and it tells people and Google what the linked page is about. The guidance asks for text that is descriptive, reasonably concise, and relevant to the page it sits on and the page it points to.

  • Written well: <a href="/bookkeeping">bookkeeping for sole traders</a>.
  • Wasted: an empty anchor, or a link labelled with a phrase that names nothing.
  • Image links: the alt attribute of the image is used as the anchor text, so describe the destination rather than the picture.

When scripts assemble anchor text after the page loads, check the rendered HTML with the URL Inspection tool instead of trusting the source view.

Every page you care about needs an inbound link

The same documentation states the rule plainly: every page you care about should have a link from at least one other page on your site, placed in context where it helps the reader.

For a service business that usually means a link from the home page to each service page, a link between related services, and links from the body copy of a guide to the service page it explains. A page reachable from the sitemap file alone is a page Google has been told about but not recommended.

A short internal link audit

  • List every URL in your sitemap and count the internal links pointing at each one.
  • Flag the URLs with none, and add a contextual link from the most relevant page that already earns impressions.
  • Replace navigation built on script events with real anchor elements.
  • Rewrite vague anchor text so it names the destination service and its location.
  • Confirm the rendered HTML of a menu link with the URL Inspection tool.

Reading the result afterwards

Search Console's Page indexing report shows which URLs Google has chosen to index and which it has left out, while the Performance report shows which pages earn clicks. When a page gains an internal link and impressions do not move after a recrawl, the link was not the constraint.
